# 首次启动：通过对话一项一项配置

这是Agent执行的引导，不是终端里连问一大串问题，也不是下载后在后台自动运行的安装钩子。Codex首次读取本仓库AGENTS.md或调用personal-media-ip时检查本机向导状态，缺失就进入引导。

## Agent执行规则

1. 定位完整仓库根目录，运行`python scripts/onboarding.py next`。只把返回的当前问题用自然中文问使用者：说明用途、当前默认值和2–3个可选方向，一次只问一项，等真实回答。
2. 用户说“保留默认”时才用`answer --id ... --keep`。没有回答、不懂、经过一段时间，均不算默认确认。回答含多个配置时可以保存其明确表达的信息供后续对应项使用，不替其决定没说的项。
3. 普通回答转换成JSON类型，再用`answer --id ... --value-json ...`。调用脚本时用安全的参数传递，不将用户文字拼成可执行命令。验证失败解释原因，仍停在当前项。用户明确修改先前已答项时，用`revise --id ... --value-json ...`，不要为改一项重置全部进度。
4. 若用户明确说“其余保持默认”，才运行`keep-remaining --confirmed-by-user`。这是使用者的快捷选择，不是Agent自己省略问项。未选择此方式时继续逐项询问所有适用可更改项，包括高级参数。
5. 平台集合先问名称和顺序，再逐项问每个平台的标题长度、策略、正文格式和参考字数。声音先选来源，只问该来源适用项；关闭配乐/水印/片尾时，相关无效项不继续问。
6. 火山API密钥和访问令牌由用户直接填写本机`.env`，不要求发在对话、不写进向导状态或Git。ChatCut查询使用者自己的音色列表，名称不当ID；无连接时说明待接入，不冒充已验证。选其他克隆服务时收集音轨/时间戳路径和显示音色名，不猜接口。
7. 用`summary`汇总选择，检查字体、Logo、配乐文件及互相矛盾的值。说明哪些服务/素材待提供。核对写作提示词与公众号模板是否需按已确认风格/字段调整（不要让旧示例覆盖用户选择）。所有适用项已答复后用`finish`保存并调用配置同步；不要把“问完配置”说成“已经合成旁白/完成视频”。
8. 配置完成后正常进入制作。已完成状态不重新问整套问题；用户明确要重配时才用`reset`。未完成的对话、Codex重启或新聊天用`next`从上次未答项继续。

## 向导覆盖范围

- 账号与内容：品牌名、视频口播文风、公众号笔风。
- 品牌：品牌/正文字体及文件、图形与下划线、透明Logo、品牌色/正文色、口号和CTA。
- 平台：集合与顺序、每个平台的标题字数、是否写品牌、标题策略、正文格式及参考字数。
- 声音：来源、音色名/ID、火山资源、语速、外部清单位置。凭证另在本机.env配置。
- 水印与片尾：开关、位置、透明度、字号、边距、画入时间、片尾总时长和静止时长。
- 音乐：开关、文件、总音量、说话/停顿倍率、截取、过渡与淡出。
- 渲染与字幕：帧率、并发、场景前后停留、各笔速/填充/抬笔参数、字幕开关/字号/安全区/长度/提前延后。
- 封面：比例、系列标签、边框与颜色。
- 写作与文章：口播篇幅、上屏限定、审校技能顺序、标题策略/候选数量、公众号字段、字数、Markdown规则、是否附摘要/标签/评论。
- 工程位置与提示词/模板文件位置。

步骤从当前JSON字段生成；新增可更改字段也会作为新步骤出现。说明性元数据和派生的重复字段不问。图形控制星芒/下划线，文风控制对应派生写作值。

白板1920×1080是代码固定画布，不是向导改一个字段就支持任意画幅。向导结束另说明这个限制，用户若要竖屏再按README的代码位置改画布、安全区和场景。配乐开头淡入当前在mix-bgm.mjs中固定1.5秒，想改需另改代码并验证；这类代码改动在最终汇总里明确说明，不伪装成JSON开关。

## 本地进度与文件

`.local/onboarding.json`保存草稿、当前待答项和已确认项；已被.gitignore排除。原配置保留到所有项处理完成，finish才写入根config.json和写作配置。同步失败恢复原配置，保留进度供修复。

每次问题包括配置文件、字段与当前值；Agent可向非技术用户只展示名称和解释，不要求用户手工编辑JSON。新克隆/新用户没有本机状态，会独立从品牌名开始。

## 用法示例

```bash
python scripts/onboarding.py next
python scripts/onboarding.py answer --id config:brand.name --value-json '"我的账号"'
python scripts/onboarding.py answer --id config:writing.videoStyle --keep
python scripts/onboarding.py summary
# 只有用户明确说“其余保持默认”之后：
python scripts/onboarding.py keep-remaining --confirmed-by-user
python scripts/onboarding.py finish
```

Codex导入/重新加载本身没有通用的执行回调，因此“自动开始”指第一次相关对话读取技能入口时，不声称安装瞬间后台执行。本向导只管配置，不自动制作或公开发布。
