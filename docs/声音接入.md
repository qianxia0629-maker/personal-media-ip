# 声音接入与时间戳格式

所有配置从根config.json读取。volc为原生合成；chatcut/external由Agent调用自己有权限的工具生成实际音轨，再导入。外部源音频使用1倍速，导入器应用tts.speed，避免重复加速。

白板每个scene对应一段音轨。运行wb scenes后，scenes/script.json记录name和segments。外部清单：

```json
{
  "scenes": [{
    "name": "01-intro",
    "audio": "voice/01-intro.mp3",
    "words": [
      {"word": "先", "startTime": 0.10, "endTime": 0.30},
      {"word": "看", "startTime": 0.30, "endTime": 0.50},
      {"word": "资料。", "startTime": 0.50, "endTime": 1.20}
    ]
  }]
}
```

这里的时间和文字仅为格式示例，不能复制为真实生产时间。单位是秒，audio相对清单位置解析。原文应与scene所有segments拼接后匹配；数字读法不一致先人工统一稿件/转写，不能猜字幕。

导入器验证词序、边界和文本，读取音频真实时长，执行保音高变速。词内多字符的字符级位置按实测词边界插值；这些是推导位置，不是每个汉字都经过独立测量，最终需听审。

ChatCut转写若返回startUs/endUs则除以1,000,000转为秒；其他服务自行按真实字段转换。不要把startMs当秒或把字幕文字错当TTS输入。

调查工程可以使用同样words作为字幕/镜头对齐输入，但不是白板scene格式：由Agent根据该Remotion工程的timeline建立对应字幕。scripts/synthesize_text.mjs保存火山结果；具体合成失败时停止，不自动换声线。

只有字幕与音画实际匹配后才交付。改变旁白或语速后重新生成/导入对应音轨和时间戳。
