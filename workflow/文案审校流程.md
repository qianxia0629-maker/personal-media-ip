# 视频文案审校：配音与视频制作的前置步骤

原作者于 2026-10-05 明确要求。适用于本项目的 whiteboard-video 与 investigation-video。每次新生成或修改文案，先完成本流程，再合成对应旁白和制作画面。用户明确要求跳过时按当次要求处理。

## 写稿前置（2026-10-12）

两类视频的所有新稿/改稿先按本项目 `文案编写提示词.md` 与 `文案编写配置.json` 编写，再进入下列三轮审校。视频只准备抖音、哔哩哔哩、小红书、微信视频号四平台标题与发布文案。微信公众号只交标题与辛辣锐评完整文章，同样先写稿再审校；保留锋芒及必要事实限定，不附摘要。

## 顺序

选题与查证 → 读取文案编写提示词.md及文案编写配置.json → 按平台编写初稿 → Humanizer-zh → stop-slop → taste-skill → 事实与口播复核 → 定稿 → 配音/字幕/画面/混音 → 成片验收。

1. Humanizer-zh：读取 skills/humanizer-zh/SKILL.md。逐段编辑中文空话、重复、模板化开头和收尾，保留作者声音、事实及确定程度；不要强行把正式调查改成玩笑口吻。
2. stop-slop：读取 skills/stop-slop/SKILL.md 及 references/phrases.md、structures.md、examples.md。复查假对比、伪深度、机械排比、故作悬念、旁观者腔和空泛术语。英文绝对禁令结合中文语境执行：必要的限定词、被动、真实三项信息和原文引语必须保留，不为了满足形式删掉事实或编造主语。不用评分替代逐句复核。
3. taste-skill：读取 skills/taste-skill/SKILL.md（技能内部名称 design-taste-frontend，来源 Leonxlnx/taste-skill 的 skills/taste-skill）。每次都检查其中与文案相关的具体表达、受众、标题、屏幕文字、信息层级及去模板规则；它主要面向前端设计，网页技术、组件、字号和布局禁令不生搬到口播或 MG。保留 RayTalk 品牌字体和色彩。无适用修改时记录已审阅，不强改。
4. 对照查证资料与初稿复核最终稿：数字、日期、来源、因果关系、限定、引用、作者立场不能改变；不得添加 使用者未提供的个人经历、情绪或事实。不把“可能”“据报道”改成确定结论。
5. 按真实口播阅读检查：自然、顺畅、句子有长短，前后衔接清楚，开头有具体观看理由；不为压时长删掉关键事实，不用模板金句凑钩子。

## 范围限定说明只上屏（Ray 明确长期规则，2026-10-12）

- 适用于之后本工作流生成的所有视频，包括 whiteboard-video 和 investigation-video。
- “这是……，不能算作……”“这仅仅是……，不是行业……”等解释材料性质、样本代表性或结论边界的说明，改成简短画面文字，在对应内容出现时注明；不写入旁白、不送入 TTS、不口播。
- 例如“这是样本测算，不能算作实际利润”可上屏为“样本测算｜非实际利润”；“这仅仅是个案，不是行业普遍情况”可上屏为“个案资料｜不代表行业整体”。这些仅为句式示例，实际说明必须符合本期证据。
- 必要的事实边界保留在画面中，并确保观众可读、停留足够、位置避开口播字幕与水印，不能只删除限定却保留容易误解的结论。
- 在文案审校阶段将口播稿与画面注记分开。画面注记单独列入场景/镜头表，与对应内容绑定；不混入语音字幕或当成待朗读文本。普通事实句中的“可能”“据报道”等准确性限定按事实需要自然保留，不能因为本规则把猜测说成确定。
- 定稿与出片验收检查：上述范围声明在画面可见，在 TTS 输入和最终音轨中未被念出。修改后的口播仍须衔接自然。

## 执行与留痕

- 审校范围包括旁白稿、开场钩子、标题、屏幕文字、封面文案和本轮生成的发布正文。发布稿在生成时按同样顺序审校；旁白必须在 TTS 前完成。
- 这是 Agent 读取技能后执行的三轮编辑，不是自动检测器或三个外部服务。仅扫描关键词或把文件写上“通过”不算完成。
- 将初稿、最终稿和一份简短审校记录存于当期已有工程/知识库，记录三轮执行情况、实际修改及事实复核结果。避免为每轮复制冗长聊天。
- 不要求 Ray 每轮确认。默认只交付最终可用稿；后台记录不夹进正文。
- whiteboard-video：旁白唯一源仍为 scenes.js，编辑 narration/segments 对应文字并重新生成旁白稿，不能只修改生成的旁白稿.md。保留 beat 划分；审校导致变化时同步场景和时间轴。
- investigation-video：先在该期知识库的权威稿件定稿，再生成音轨、字幕和镜头表；改已配音文字需更新对应音轨与对齐。
- 新增或修改的文字必须重新审校，再生成对应视频。明确标注完成状态，未审校完不得声称可直接出片。

## 公众号 Markdown 审校补充
依据项目《微信公众号文章模板.md》和《银发直播间》样例保留短段落、分节、重点加粗与辛辣锐评力度。三轮审校同时检查 Markdown 结构、引用归因和虚构细节；最终仅标题与正文，MD/TXT均保留 Markdown 标记。

## 微信视频号标题符号复核

主推及备选标题均≤16字（含标点和空格）；不含其他特殊字符，符号仅支持书名号、引号、冒号、加号、问号、百分号、摄氏度；逗号改为空格，不使用emoji。书名号、引号及其常见中英文形式按配置的 `titleAllowedSymbols` 校验，`titleAllowedSymbolSequences` 默认支持 `°C`。检查主推和备选标题；禁用符号不得带入最终可复制标题。
