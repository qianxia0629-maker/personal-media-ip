# 制作与验收

## 工程方式

在新工作目录保留可回退版本，不覆盖原稿、原素材与已交付成片。只精修时不重配音、不重跑素材搜索；源质量或匹配不足才补源。安装依赖前核对原项目已有 Remotion/React 版本，不凭记忆升级。

帧动画以 `useCurrentFrame` 和固定 fps 驱动；文字的稳定期与背景的轻微运动独立。一个变量控制资金比例条，路径源点由各段中心求出，与对应标签连接。相邻金额出现后保留，最终等式停稳；动效结束后结果不能消失。

包内示例是可运行的当前确认基线，不是必须套用的三卡模板。跨镜用物件延续、证据区域聚焦或声音接续；复杂图表可占专门解释镜头。10 分钟以上的长片需要不同真实素材与叙事推进，不能把这 30 秒循环扩展。

## 渲染前的易错点

- 配音句 json 必须带非空 `words`（火山逐字时间戳）；为空说明 TTS 开关或资源不对（2.0 音色要 `enable_subtitle`），先修合成再对字幕，不要默认去跑 whisper。
- 裁切文件若按序号命名，镜头表改动后旧文件会被同名复用，画面与角标错位而渲染不报错。改镜头表后清空裁切目录重切，或按源+起点+帧数命名。
- 竖屏原片不要整幅拉伸或硬裁成横屏：去掉原片顶部标题条与底部字幕后竖幅内嵌，底用同源模糊压暗；裁切 y 值先抽帧确认。

- 素材、音频和字体实际复制到新工程 `public`。本机实测 `public` 内符号链接会被静态资源服务跳过并导致 404；不要用它节省空间。`node_modules` 可复用已有依赖目录。
- `OffthreadVideo` 与不透明 `AbsoluteFill` 同级时，显式指定定位与层级；否则视频可能被背景盖住而渲染不报错。
- 字标位置、Sans 字体、真实素材、字幕、最后一个 MG 状态先各抽关键帧；检查控制台 404。不能只看 render 成功。
- 确保源视频时长覆盖使用区间。证据位置与裁切按原像素算，不能用 CSS 尺寸误裁原始高清截图。
- 查看磁盘空间和正在运行的渲染；每个任务独立日志。不要同时写同一输出，不能假设发送终止后旧进程一定退出。

## 开场单独验收

整片导出前，检查前约5秒是否已经交代话题和观看理由；隐藏标题与封面后，开头仍应独立成立。前约30秒连同配音连续检查：动作是否推进，是否又回到卡片讲解，数字是否挡住主体，来源说明和字幕是否清楚。抽帧只验证构图，不能据此宣布钩子有效或节奏流畅；未连续观看的范围如实记录。

用户指出开场无钩子或像PPT时，先把已授权的改稿和画面做成带声音、字幕的可播放结果，不只交建议或提示词。更换主要视觉语言可先交开场样片；它不代表整片已更新，也不形成每次改动都要重新审批的规则。修订整片时检查新旧旁白衔接、重复内容、音量和字幕偏移。

## 本风格的时间预算

以文字完全出现且稳定为起点：短花字约 2.5–3 秒；完整短句按字数约 4 秒起；证据入场/高亮后约 5 秒，整体常为 8–9 秒；数字最终汇总约 3 秒起。字幕继续按实际语音切句，不因画面预算而与音频错位。

语音窗口不足时简化卡、减少文字或延长解释镜头；不要把一套 8.5 秒证物动画塞进 3 秒镜头。只有用户允许改稿才能调整旁白。所有文字都不需要同时动，镜头快慢也不等于信息快慢。

## 长片与片尾增量检查

长片先按 [长片制作流程](long-form-workflow.md) 核对逐段素材覆盖，检查真实动态出现时长、去重源区间和复用情况。不能用视频文件数量、MP4扩展名或MG运动来证明真实动态占比。

仅补CTA时，保留此前确认的正文与声音；追加末段，沿用原声线和语速，按新音频重对齐末段字幕。检查拼接处音画、结尾尾音、字幕退出和最终留白；更新主成片、字幕、时长与交付说明。存在旧文件不代表新版本已经合成。

## 交付前

1. 成片必须已混入闪避配乐并记录说话段/句间隙电平；全片解码、检查总时长/fps/尺寸和非静音音轨；参考对话类旁白混音约 -16 LUFS、真峰值约 -2 dBTP，按平台规范和实际效果调整。
2. 检测黑帧后人工判断，深色品牌底不等于黑帧；无黑帧也不能证明视频层正常。
3. 实拍、证据入场结束/强调完成/退场、MG 初始/中间/最终、转场前后和片尾抽帧，复核字幕遮挡、Logo 和来源。
4. 动态播放检查可读时间与音画一致；字幕、声音的检查范围如实写。拼板不能证明动作流畅或完整听审，未人工逐秒检查就明确说明。
5. 交付用户请求的样片或整片、来源说明与简短 QA；按需求附封面、字幕、发布文本。制作授权不自动包含公开发布。

只宣称实际完成的检查。文件路径必须指向可播放成片，不能把旧 MP4 当新版本交付。

## 拼贴画面的额外检查

检查描边后的主体实际边界，而不只看图片盒子；蛋糕尖端等透明图形可能进入文字区。亮色物件后面的白色金额须移到净空区或补足对比，不用更多阴影代替合理构图。轻颗粒、浮尘和视差不能使已出现的文字持续抖动。对标抽帧只能证明静态层次，未连续观看时不宣称验证了转场曲线或逐秒音画一致。
