最新视觉制作参考为 [视觉升级 v2](visual-collage-v2.md)。本页保留旧版品牌、阅读时间与资金机制参考，不再作为唯一视觉基线。

用户于 2026-09-09 在查看品牌对齐的 30 秒视频后明确确认“OK 可以了”，随后要求沉淀成新 Skill。只把该确认用于这套视觉与工作方法，不扩张为所有选题都要同一张图表。

## 先看

- 原始 30 秒样片、拼板与校验和未随开源仓库附带；公开样片见 [assets/sample-preview.mp4](../assets/sample-preview.mp4)。

这是《幽灵外卖》竞价和资金拆解节选，不是可循环拼成整片的模板：

| 时间 | 内容 | 设计任务 |
|---|---|---|
| 0–5.13 秒 | 100、90、80 元竞价 | 真实网店资料＋逐项报价；最后一项完整出现后约 2.7 秒稳定阅读 |
| 5.13–14.23 秒 | 付款前后的选择 | 网店证据窗口＋机制对比，约 9 秒连续停留 |
| 14.23–30 秒 | 252.3 元的分配 | 按比例的色条、路径、逐项金额，最后保留 76.8 到手说明 |

原报道素材为 480×270，这属于样例的质量限制，不是以后新片的清晰度标准。新任务仍应优先取得更清晰的主体原件。样例只做视觉抽帧和自动音画检查，没有逐秒人工听审的记录。

## 最小工程

`template/remotion/` 保留可运行代码、原样例完整时间戳（仅使用其中约 30 秒）、30 秒音轨、Noto Sans SC、实际使用的 shop 图片和视频。只复制必要素材，没有 node_modules、缓存、密钥、系统字体。

本包 `assets/BrandStamp.jsx` 已被该示例工程实际导入，以便检验复用路径。先将 **这两个资产一起**复制到新的工作区，保持 `template/remotion/index.jsx` 对 `../../assets/BrandStamp.jsx` 的相对关系，再运行：

```sh
# 在复制后的 template/remotion 中，使用已有的兼容依赖，或依 package.json 安装。
npm install
npm run still -- brand-check.png --frame=820 --scale=0.5
npm run render
```

也可复用本机 `已安装同版本依赖的 node_modules`，实际版本以工程为准。样例 package.json 固定当次使用的 Remotion 4.0.508 / React 19.2.8，避免安装时静默漂移。SignPainter 需本机已安装；跨平台使用前核对字形。不要将此片声线、案情和全文复制到新片。
